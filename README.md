# Курсовая работа: Анализ транзакций

## Реализованный функционал:
1. **Отчеты (`src/reports.py`)**:
   - Декоратор `save_report` для сохранения результатов в файл.
   - Функция `spending_by_category` (траты по категории за 3 месяца).
   - Функция `spending_by_weekday` (средние траты по дням недели).
   - Функция `spending_by_workday` (средние траты в рабочие/выходные дни).

2. **Веб-страницы (`src/views.py`)**:
   - Функция `main_page`, которая генерирует JSON для главной страницы (приветствие, карты, топ-5 транзакций, курсы валют, акции, расходы/доходы).

3. **Сервисы (`src/services.py`)**:
   - Функция `simple_search` (простой поиск по описанию и категории).

## Тестирование:
- Покрытие тестами: **> 80%**
- Все тесты запускаются командой `poetry run pytest`.
- Линтеры (`flake8`, `isort`, `mypy`) не выдают ошибок.
